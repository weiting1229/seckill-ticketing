# 首頁橫式活動卡與活動輪播設計

## 目標

首頁活動圖片統一以 1536×1024（3:2）為主要來源比例，活動列表改為橫式卡片，並在導覽列下方加入可由管理員指定內容與順序的活動輪播。

## 已確認的產品決策

- 維持圖片 URL 模式，不導入檔案上傳、物件儲存或圖片裁切服務。
- 活動卡與輪播圖片框皆使用 3:2。
- 圖片採 `object-fit: contain`，確保非標準比例圖片仍不會遭到裁切；框體以中性背景補足留白。
- 首頁順序為：網站導覽列、活動輪播、精簡搜尋區、活動卡列表。
- 輪播由管理員透過「首頁輪播」開關與「輪播排序」數字控制。
- 公開輪播只回傳已發布的活動，草稿與已關閉活動不得曝光。

## 資料與後端

在 `events` 資料表加入：

- `featured`: 是否列入首頁輪播，預設 `false`。
- `featured_order`: 輪播排序，可為空。

活動建立與編輯 API 接受這兩個欄位，管理後台列表回傳欄位值。新增公開唯讀輪播端點，僅查詢 `PUBLISHED` 且 `featured = true` 的活動，依 `featured_order`、活動時間與 ID 穩定排序，並限制回傳數量。

## 首頁元件

新增獨立 `FeaturedEventCarousel` 元件，接收活動摘要陣列，不自行發送 API，以保持資料流單純且易測試。

桌面顯示中央主卡與左右相鄰預覽；平板縮小相鄰預覽；手機一次顯示一張。輪播具備：

- 約 5 秒自動播放。
- 左右控制按鈕與頁面指示點。
- 滑鼠停留、鍵盤聚焦及觸控操作時暫停。
- 鍵盤左右方向鍵操作。
- `prefers-reduced-motion` 下停用自動播放與滑動動畫。
- 活動圖、控制按鈕與狀態變化提供適當替代文字及 ARIA 標示。

若只有一筆資料，隱藏切換控制；沒有資料時不渲染輪播區，首頁由精簡搜尋區開始。

## 活動卡

卡片圖片區由 3:4 改為 3:2。桌面維持三欄、平板兩欄、手機一欄。圖片保持完整顯示，日期與狀態徽章維持在圖片區，文字資訊位於圖片下方。

無圖片或圖片載入失敗時，使用既有生成式海報元件的橫幅變體，避免版面跳動。

## 後台

活動建立／編輯表單新增：

- 「顯示於首頁輪播」開關。
- 「輪播排序」數字欄位，只有開關啟用時可操作。
- 3:2 圖片預覽與 1536×1024 建議提示。

排序值以非負整數驗證。未啟用輪播時送出 `featured = false` 且 `featuredOrder = null`。

## 錯誤處理與效能

- 輪播載入失敗不阻斷一般活動列表與搜尋。
- 圖片設定固定 3:2 空間，避免累積版面位移。
- 輪播主圖優先載入，活動列表圖片維持 lazy loading。
- 圖片 URL 載入失敗時沿用現有 fallback。

## 測試與驗收

- 後端整合測試驗證公開輪播只回傳符合狀態的活動及正確排序。
- 後端管理流程測試驗證欄位建立與更新。
- 前端單元測試驗證輪播索引循環、單筆資料、減少動態效果與暫停規則。
- 前端建置、型別檢查、lint 與既有測試全數通過。
- 手動檢查 375px、768px、1024px、1440px，確認無水平捲動、圖片不裁切、鍵盤可操作。
